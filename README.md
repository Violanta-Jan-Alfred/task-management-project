# Task Management App

This is a simple **Task Management App** developed as part of our **App Development** course. It utilizes **basic HTML, CSS, and JavaScript** to provide a simple yet effective task management system.

## Features
- ✅ Add, edit, and delete tasks  
- 📌 Mark tasks as complete or pending  
- 🔄 Save tasks in local storage for persistence  
- 🎨 Simple and responsive UI  

## Technologies Used
- 🏗 **HTML** for structure  
- 🎨 **CSS** for styling  
- ⚡ **JavaScript** for interactivity  

## Purpose  
This project was created for **learning purposes** to demonstrate **basic front-end development** and working with the **Document Object Model (DOM) and Local Storage** in JavaScript.
